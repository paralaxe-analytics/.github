## English

This repository holds the public profile and organization-wide defaults for **Paralaxe Analytics** on GitHub.

### What's here

| Path | Purpose |
|---|---|
| `profile/README.md` | The profile shown on [github.com/paralaxe-analytics](https://github.com/paralaxe-analytics). |

Community health files placed at the root of this repository (such as `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md` or issue templates in `ISSUE_TEMPLATE/`) apply by default to every Paralaxe Analytics repository that doesn't have its own version.

### Making changes

Changes go through a pull request to the default branch. Once merged, updates to `profile/README.md` appear on the organization page right away.

The profile is bilingual. Any change to one language must be made in the other as well.

## Português

Este repositório reúne o perfil público e as configurações padrão da **Paralaxe Analytics** no GitHub.

### O que tem aqui

| Caminho | Finalidade |
|---|---|
| `profile/README.md` | O perfil exibido em [github.com/paralaxe-analytics](https://github.com/paralaxe-analytics). |

Arquivos de padrões da comunidade colocados na raiz deste repositório (como `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md` ou modelos de issue em `ISSUE_TEMPLATE/`) valem por padrão para todos os repositórios da Paralaxe Analytics que não tenham a sua própria versão.

### Como alterar

Toda alteração passa por um pull request para a branch principal. Depois do merge, as mudanças em `profile/README.md` aparecem na página da organização imediatamente.

O perfil é bilíngue. Toda alteração feita em um idioma deve ser feita também no outro.
